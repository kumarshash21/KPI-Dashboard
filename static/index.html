Notes & rules

  • Counting rule: Status = Solved, Category = Software (Hardware excluded), Type ≠ Alert (Alerts excluded). Each case counts once.
  • Incident vs SR/Query: Incidents are Type = Incident; every other non-Alert type is SR/Query.
  • Window & dates: End Time of Incident only (not ClosedDate / LastModifiedDate / CaseHistory), converted to IST then bucketed by day and week (Sun–Sat). Window = today−37 to today−7, extended back to the Sunday so the first week is complete; the last week is tagged Partial.
  • Ownership: a ticket is credited to its current owner as of today. Non-roster owners are counted separately (all-owner total, non-roster share, top owners).
  • Averages: count ÷ Monday–Friday days in the period; weekend tickets still count in totals. Individual leaves are not adjusted (Weekly Off is blank).
  • Roster: fixed email lists (52 engineers); POD Name in Salesforce is not used. Engineers not found in Salesforce show zeros with “not in Salesforce yet”.
